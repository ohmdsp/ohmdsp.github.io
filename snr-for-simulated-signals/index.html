SNR for Simulated Signals

Setting noise level for a target SNR


Jul 30, 2024 DSP SNR Simulation MATLAB

This is a short note on how to set the noise level in a simulation to hit a desired SNR.

Let

$$ \sigma_s^2 = \text{var(signal)}, \quad \sigma_w^2 = \text{var(noise)}. $$

Then SNR in dB is

$$ SNR_{dB} = 10\log_{10}\left(\frac{\sigma_s^2}{\sigma_w^2}\right). $$

If you generate unit-variance noise $w[n]$ and scale it by a constant $p$ (so noise is $pw[n]$), then

$$ SNR_{dB} = 20\log_{10}\left(\frac{\sigma_s}{p\sigma_{w}}\right) $$

which gives

$$ p = \frac{\sigma_s}{10^{SNR_{dB}/20} \cdot \sigma_{w}}. $$

For unit-variance noise, $\sigma_{w} \approx 1$, so this reduces to a very simple scaling rule.

MATLAB snippet (random BPSK)

rng(1);

% Parameters
N = 1e5;                 % number of symbols
snrDbTarget = 8;         % desired SNR in dB

% Random BPSK: bits -> symbols in {-1, +1}
bits = randi([0 1], N, 1);
s = 2*bits - 1;

% Signal standard deviation
sigmaS = std(s);

% Unit-variance white Gaussian noise
w = randn(N,1);
sigmaW = std(w);

% Scale factor to achieve target SNR
p = sigmaS / (10^(snrDbTarget/20) * sigmaW);

% Noisy received signal
r = s + p*w;

% Measured SNR
noiseActual = r - s;
snrDbMeasured = 10*log10(var(s) / var(noiseActual));

fprintf('Target SNR:   %.2f dB\n', snrDbTarget);
fprintf('Measured SNR: %.2f dB\n', snrDbMeasured);

The measured SNR should be close to the target SNR, with small variation due to finite sample size.
