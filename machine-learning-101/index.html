Probability, Uncertainty, and Core Concepts


Mar 29, 2019 Machine Learning Probability Statistics Linear Regression

In real-world signal processing and machine learning, we often deal with uncertain or even stochastic (i.e. non-deterministic) quantities. There are three main sources of uncertainty worth mentioning:

  1. Inherent stochastic systems — e.g. the dynamics of sub-atomic particles.
  2. Incomplete observations — Even deterministic systems appear stochastic when we cannot observe all the variables that drive the system’s behavior.
  3. Incomplete modeling — When we model a system but discard information we have observed (e.g. discrete sampling of position).

Two Kinds of Probability

Two interpretations of probability are useful for representing and reasoning about uncertainty:

  • Frequentist probability — rates at which events occur (e.g. drawing cards, flipping a coin).
  • Bayesian probability — qualitative levels of certainty (e.g. a 40% chance of having the flu).

Both should behave the same when reasoning about uncertainty. Probability theory provides a set of formal rules for determining the likelihood of a proposition being true, given the likelihood of other propositions.

Random Variables and Probability Distributions

A random variable is a variable that can take on different values randomly. It is a description of the states possible, and must be coupled with a probability distribution that specifies how likely each state is to occur. There are two types: discrete and continuous.

Probability Mass Function (PMF)

For discrete random variables, the PMF is written $P(x)$, denoting the probability that $X = x$. The joint probability distribution over two variables is

$$P(X = x,\ Y = y) = P(x, y).$$

A valid PMF must satisfy:

  1. The domain of $P$ must be the set of all possible states of $x$.
  2. $\forall\ x \in \mathcal{X},\quad 0 \leq P(x) \leq 1$.
  3. $\displaystyle\sum_{x \in \mathcal{X}} P(x) = 1$.

Example — rolling a die (k = 6 sides):

$$P(X = x_i) = \frac{1}{k}, \qquad \sum_{i=1}^{6} P(X = x_i) = \sum_{i=1}^{6} \frac{1}{6} = \frac{6}{6} = 1.$$

Probability Density Function (PDF)

For continuous random variables, the PDF is written $p(x)$. A valid PDF must satisfy:

  1. The domain of $p$ must be the set of all possible states of $x$.
  2. $\forall\ x \in \mathcal{X},\quad p(x) \geq 0$.
  3. $\displaystyle\int p(x), dx = 1$.

Conditional Probability

The conditional probability is the probability of some event, given that another event has happened:

$$P(Y = y \mid X = x) \quad \longrightarrow \quad \text{probability that } Y = y \text{ given } X = x.$$

$$P(Y = y \mid X = x) = \frac{P(Y = y,\ X = x)}{P(X = x)}$$

Expected Value, Variance, and Covariance

Expected Value

The expected value is the average (mean) value that $f$ takes when $x$ is drawn from $P(x)$:

$$\mathbb{E}_{x \sim P}\bigl[f(x)\bigr] = \sum_{x} P(x), f(x) \qquad \text{(discrete)}$$

$$\mathbb{E}_{x \sim p}\bigl[f(x)\bigr] = \int p(x), f(x), dx = \mathbb{E}\bigl[f(x)\bigr] \qquad \text{(continuous)}$$

Variance

Variance measures how much the values of a function of a random variable $x$ vary:

$$\text{Var}\bigl(f(x)\bigr) = \mathbb{E}!\left[\bigl(f(x) - \mathbb{E}[f(x)]\bigr)^2\right].$$

The standard deviation is $\sqrt{\text{Var}}$.

Covariance

Covariance measures how much two values are linearly related to each other:

$$\text{Cov}\bigl(f(x),, g(y)\bigr) = \mathbb{E}!\Bigl[\bigl(f(x) - \mathbb{E}[f(x)]\bigr)\bigl(g(y) - \mathbb{E}[g(y)]\bigr)\Bigr].$$

Note: Linearly independent variables $\Rightarrow$ Cov $= 0$.

Useful Functions for Probability Distributions

Sigmoid

$$\sigma(x) = \frac{1}{1 + \exp(-x)}$$

Used to represent probability distributions over binary variables. Commonly used to produce the parameter $\phi$ of a Bernoulli distribution, since its range is $(0, 1)$:

$$ \begin{aligned} P(x = 1) &= \phi \\ P(x = 0) &= 1 - \phi \\ P(x = x) &= \phi^{x}(1 - \phi)^{1-x} \end{aligned} $$

Softplus

$$\zeta(x) = \log!\bigl(1 + \exp(x)\bigr)$$

Useful for producing $\beta$ or $\sigma$ parameters of the normal distribution. This is a smooth approximation to ReLU:

$$f(x) = \max(0,, x).$$

Softmax

Used whenever we want to represent a probability distribution over a discrete variable with $n$ possible values:

$$\text{softmax}(z)_i = \frac{\exp(z_i)}{\displaystyle\sum_{j} \exp(z_j)}$$

Machine Learning Tasks

  • Classification — Produce a function $f : \mathbb{R}^n \to \{1, \ldots, k\}$, mapping an input vector $\vec{x}$ to a category label $y = f(\vec{x})$.

  • Regression — Predict a numerical value given some input. The ML algorithm outputs a function $f : \mathbb{R}^n \to \mathbb{R}$.

  • Structured Output — Output is a vector with important relationships between different elements (e.g. image segmentation, image captioning).

  • Anomaly Detection — Identify unusual examples in a dataset.

  • Synthesis and Sampling — Generate new examples that are similar to those in the training data.

  • Denoising — Recover a clean signal from a corrupted input.

  • Probability Density Estimation / PMF — Learn a function $p_{\text{model}}(\vec{x})$ on the space from which samples are drawn.

ML Algorithm Categories and Performance

Performance Measure

How well does the algorithm work? For classification this is typically accuracy or error rate. It can be difficult to decide exactly what should be measured for a given problem.

Algorithm Categories

  • Supervised — Given $\vec{y}$ and $\vec{x}$, learn to predict $\vec{y}$ from $\vec{x}$. The goal is to estimate $p(\vec{y} \mid \vec{x})$.
  • Unsupervised — Learn the entire PDF that generated the dataset, without labeled outputs.

Linear Regression

Linear regression is a supervised learning task where:

  • Input: $\vec{x} \in \mathbb{R}^n$ (vector)
  • Output: $y \in \mathbb{R}$ (scalar)

We define the predicted output as

$$\hat{y} = \vec{w}^{\top} \vec{x}, \qquad \vec{w} \in \mathbb{R}^n \ \text{(parameters)}.$$

The task is to predict $y$ from $\vec{x}$ by learning the weight vector $\vec{w}$. The standard performance measure is Mean Squared Error (MSE):

$$\text{MSE} = \frac{1}{m} \sum_{i=1}^{m} \Bigl(\hat{y}_i^{(\text{test})} - y_i^{(\text{test})}\Bigr)^{2}$$
